## Google Teachable Machine

| Question | Detail |
|---|---|
| Official entry | [Google Teachable Machine](https://teachablemachine.withgoogle.com/) |
| Age / learner fit | 10–16 with adult support (editorial) |
| Suggested finished result | A two-object classifier tested on held-out examples |
| What is free | Browser model training/export path; optional hosting/cloud choices |
| Account / device setup | Browser JavaScript and optional camera/mic; saving/export choices differ |
| Primary evidence | [Provider source](https://dev.teachablemachine.withgoogle.com/) |
| Evidence and access | Google-owned explanatory page describes training, testing, local-use option and free model download/hosting. Production homepage loaded with incomplete text in our browser; functional training was not tested. |
| Important boundary | Access-limited entry: use only after an adult confirms the production page works. Use objects and permitted sample files. Do not assume every save/share option keeps data on-device. |
