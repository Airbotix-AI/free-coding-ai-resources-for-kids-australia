# What “free” means in this directory

| Label or condition | What it means for a family |
|---|---|
| Free editor or public lesson | The listed learning material or basic creation path has no fee; internet/device costs remain yours |
| Free for eligible AU/NZ students | Grok Academy’s provider policy is country/student-specific; check the actual account eligibility |
| Optional account | Basic use and cloud saving/sharing can have different requirements; exporting a local backup may be a better starting option |
| Simulator | The editor can simulate a device; a physical board, kit and accessories are separate purchases |
| API-key-dependent path | Cloud usage limits and billing can apply; this repository’s beginner path excludes Machine Learning for Kids text/API setup |
| Public directory | Hub-owned reading is accessible, but third-party results can be paid |
| Access-limited | Sources identify the learning tool, but our live view was incomplete; confirm access before planning a lesson |

## Before a child starts

An adult should check the specific tool’s current terms and age/account route, choose a suitable project, and understand how to keep the work. For classifier activities, use ordinary objects, fictional examples or permitted sample files rather than a child’s face, school documents or private conversations. Sharing a project publicly is a separate choice from making it.

Learning AI does not require giving a child an unrestricted general-purpose chatbot. Day of AI, Experience AI, paper model-evaluation activities and provider-hosted simulations can teach core ideas without that step. An adult’s account does not automatically authorise a child’s use of a service.

## Practical zero-extra-cost starts

- Paper algorithms: CS Unplugged with materials already at home.
- Browser puzzles: Blockly Games on its maintainer-linked domain.
- Game creation: MakeCode Arcade simulator on an existing compatible computer.
- Physical-computing concepts: MakeCode micro:bit simulator without buying a board.
- AI concepts: adult-selected Day of AI or Experience AI materials; check educator download access first.

These are access choices, not a claim that every external site works on every device. No purchase, provider registration, child upload or paid API was performed to prepare this directory.
