# Four free learning paths

These are editorial sequences. Choose readiness and interest over speed. There is no promise to finish in a fixed number of sessions, and none requires a paid chatbot or hardware kit.

| Path | Try, explain, improve | Finished evidence | Corresponding article |
|---|---|---|---|
| Ages 5–7 with an adult | Give paper instructions using CS Unplugged; make a two-scene ScratchJr story; change the order and predict what happens | A replayable story and one explanation of sequence | [What age should kids start learning AI?](https://airbotix.ai/blog/what-age-should-kids-start-learning-ai-sydney-parents) |
| Ages 8–11, game maker | Choose a Code Club Australia Scratch guide; build the core; add one original rule; ask a family member to test it | Playable game, test note and one improvement | [First projects matched to interests](https://airbotix.ai/blog/first-coding-projects-kids-australia-match-interest) |
| Ages 12–16, text programming | Choose a suitable Grok Python course or software-only Raspberry Pi project; predict output; debug a mistake; add a feature | Working program with normal and edge-case tests | [Compare coding platforms](https://airbotix.ai/blog/best-coding-platforms-for-kids-australia) |
| AI literacy with an adult/teacher | Select the age strand in Day of AI or Experience AI; distinguish labels from predictions; test unseen examples; discuss a failure | Evaluation record with a limitation and a proposed change | [AI coding: where to start](https://airbotix.ai/blog/ai-coding-for-kids-what-it-is-and-where-to-start) |

## A small weekly rhythm

Choose one tool and one result. First see a relevant example, then build a small version, explain a choice, test it and make one change. Save the project in a way the family understands before changing devices or clearing browser storage. If a login, payment or hardware requirement blocks progress, switch to an explicitly compatible free path rather than signing up blindly.

## What to keep

| Evidence | A useful question |
|---|---|
| Finished artifact | Can another person open, read, run or play it? |
| Child’s explanation | What did you choose, and why? |
| Test evidence | What did you expect and what happened? |
| Improvement | What changed after the test? |
