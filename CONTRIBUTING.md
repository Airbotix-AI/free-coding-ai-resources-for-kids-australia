# Contributing and corrections

Suggest a resource with its official entry, primary evidence for the free path, review date, learner fit, account/device requirements and a concrete result a child could make or explain. Mark editorial age suggestions separately from provider terms. Disclose limits, paid upgrades, country eligibility, hardware and cloud/API costs.

Keep every repository file Markdown. No workflows, executables, JSON/CSV datasets, copied lesson packs, private contact data, credentials or affiliate links. This directory links external materials; it does not relicense them. Add useful resources rather than duplicate promotional entries.

Check relative Markdown links and factual transcription without CI or builds. Do not create child accounts or upload children's data to verify a listing. Preserve evidence gaps; a working homepage does not establish full course access.
